# 03 数学 `crossquant.mathematics`

数学子包提供 **度量、表示与结构**：分布之间的距离（最优传输、信息几何）、路径的代数表示（签名）、动力系统的线性化（Koopman）、数据的拓扑（持续同调）、尾部与依赖（极值理论、copula）、随机分析的数值方法（SDE、QMC、FFT 定价）以及多尺度分析（小波、分数阶差分）。

每节结构：**学科来源 → 量化映射 → 核心公式 → 接口 → 注意事项**。

---

## 1. `optimal_transport` —— 最优传输与分布距离

**来源**：Monge (1781) / Kantorovich (1942)；Cuturi (2013) Sinkhorn 熵正则化；Villani 的 Wasserstein 几何。

**映射**
- **分布漂移监测**：滚动窗口收益分布与参考分布的 W₁ 距离。
- **分布鲁棒组合（DRO）**：Blanchet–Chen–Zhou (2022) 证明以 Wasserstein 球为歧义集的均值-方差问题等价于一个带正则项的凸问题，`delta` 控制保守程度。
- **两样本检验**：MMD 置换检验、能量距离。

**核心公式**：一维 W_p^p = ∫₀¹ |F⁻¹(u) − G⁻¹(u)|^p du；Sinkhorn 在 log 域迭代 f ← ε log a − ε LSE((g − C)/ε)；高斯间 W₂² = ‖μ₁−μ₂‖² + tr(Σ₁ + Σ₂ − 2(Σ₂^{1/2}Σ₁Σ₂^{1/2})^{1/2})（Bures）。

**接口**：`wasserstein_1d(x, y, p)`、`wasserstein_barycenter_1d`、`rolling_wasserstein`、`sinkhorn(a, b, C, eps)`、`sinkhorn_divergence`、`gaussian_w2`、`wasserstein_dro_mean_variance(mu, Sigma, delta, target_return, long_only)`、`mmd`、`mmd_permutation_test`、`energy_distance`。

## 2. `signatures` —— 路径签名与粗糙路径

**来源**：Chen (1957) 迭代积分；Lyons (1998) 粗糙路径理论；Levin–Lyons–Ni (2013) 签名作为特征。

**映射**：签名 S(X) = (1, ∫dX, ∫∫dX⊗dX, …) 是路径的“泰勒展开”，对时间重参数化不变、唯一刻画路径（含时间增广后）；任何连续路径泛函都能被签名的线性函数逼近 → 线性模型 + 签名特征 = 通用非线性路径模型。**签名交易**（Futter–Horvath–Wiese 2023）：把均值-方差推广到路径依赖策略，最优权重 ℓ* = (2λ)⁻¹(Cov(Y)+ridge)⁻¹E[Y] 有闭式。

**核心公式**：分段线性路径的签名 = 各段 exp⊗(Δx) 的 Chen 乘积；对数签名用 BCH；二维 Lévy 面积 = ½(S^{12} − S^{21})；lead-lag 变换使二次变差进入签名。

**接口**：`signature(path, depth) -> list`、`signature_flat`、`log_signature`、`levy_area`、`add_time`、`lead_lag`、`basepoint`、`sliding_signature_features(series, window, depth, step, transform, normalize)`、`SignatureTrading(window, depth, risk_aversion, ridge, transform).fit(x).positions(x) / backtest(x)`。

**注意**：特征数随深度指数增长（d 维路径深度 m：(d^{m+1}−1)/(d−1)），深度 2–3 即可；已验证 Chen 恒等式与圆周路径的对数签名面积 = π。

## 3. `information_geometry` —— 信息几何

**来源**：Rao (1945) 用 Fisher 信息定义统计流形的度量；Amari 的 α-联络与自然梯度；Cover (1991) 通用组合；Helmbold 等 (1998) 指数梯度。

**映射**
- **分布变化的内在距离**：高斯族的 Fisher–Rao 距离 d = √2·arccosh(1 + [(μ₁−μ₂)² + 2(σ₁−σ₂)²]/(4σ₁σ₂))，对尺度不敏感。
- **散度家族**：KL / JS / Hellinger / α / Bregman。
- **在线组合选择 = 概率单纯形上的镜像下降**：EG 更新 w ← w·exp(η x/⟨w,x⟩)/Z；Cover 通用组合 = 所有恒定再平衡组合按历史财富加权。

**接口**：`fisher_information_gaussian`、`fisher_rao_gaussian(mu1, s1, mu2, s2)`、`kl_gaussian`、`kl_divergence`、`js_divergence`、`hellinger_distance`、`alpha_divergence`、`bregman_divergence`、`natural_gradient_step`、`rolling_fisher_rao`、`exponentiated_gradient(price_relatives, eta)`、`constant_rebalanced`、`universal_portfolio`、`best_crp_in_hindsight`。

## 4. `sde` —— 随机微分方程与（拟）蒙特卡洛

**来源**：Itô 积分；Kloeden–Platen 数值 SDE；Halton / Sobol 低偏差序列；布朗桥构造。

**接口**：`euler_maruyama(drift, diffusion, x0, T, n_steps, n_paths)`、`milstein`、`simulate_gbm`、`simulate_cir`（完全截断，保证非负）、`simulate_heston(S0, v0, mu, kappa, theta, xi, rho, T, n_steps, n_paths)`、`simulate_merton_jump`、`halton`、`brownian_bridge_path`、`qmc_normals`、`antithetic_estimate`、`control_variate`。

**注意**：Milstein 对乘性噪声强收敛阶 1.0（EM 为 0.5）；QMC + 布朗桥把方差集中在低维，期权定价误差显著下降。

## 5. `fracdiff` —— 分数阶差分

**来源**：Hosking (1981) ARFIMA；López de Prado (2018) 的固定窗分数阶差分（FFD）。

**映射**：价格序列非平稳、收益序列无记忆；取 d ∈ (0,1) 使序列刚好平稳又保留最多记忆。权重 w_k = −w_{k−1}(d−k+1)/k，FFD 截断到 |w_k| < threshold。

**接口**：`frac_diff_weights(d, size)`、`frac_diff_ffd(x, d, threshold)`、`frac_diff_expanding`、`find_min_d(x, d_grid, alpha, regression)`（最小的通过 ADF 的 d）。

## 7. `koopman` —— Koopman 算子、DMD 与 SSA

**来源**：Koopman (1931) 把非线性动力系统提升为可观测量空间上的线性算子；Schmid (2010) 流体力学的 DMD；Broomhead–King (1986) 的 SSA。

**映射**：DMD 从快照对 (X, X') 求 A ≈ X'X⁺，特征值给出各模态的增长 / 频率 → 趋势、周期的分解与外推（Mann–Kutz 2016 用于交易）；Hankel-DMD 用时滞嵌入处理标量序列；SSA 的轨迹矩阵 SVD 做趋势-周期-噪声分离与预测。

**接口**：`dmd(X, rank, dt)`、`dmd_predict`、`hankel_matrix`、`hankel_dmd(x, delay, rank)`、`ssa(x, window, n_components, groups)`、`ssa_forecast`。

**注意**：对线性系统 DMD 特征值精确恢复；金融序列需配合滚动窗口与低秩截断防止过拟合。

## 8. `tda` —— 拓扑数据分析

**来源**：Edelsbrunner–Harer 持续同调；Bubenik (2015) 持续景观。

**映射**：Gidea–Katz (2018) 把滚动窗口的多资产收益点云做 Vietoris–Rips 过滤，持续景观的 L¹/L² 范数在 2000、2008 崩盘前显著上升；本库用纯 numpy（并查集 H0 + Z₂ 边界矩阵约简 H1）实现。

**接口**：`vietoris_rips_persistence(points, max_dim, max_edge)`、`persistence_landscape(diagram, k_max, grid)`、`landscape_norm`、`total_persistence`、`tda_crash_indicator(returns, window, step, p_list)`。

**注意**：H1 的边界矩阵约简复杂度随点数快速增长，窗口建议 ≤ 60 点、4–10 维。

---

## 9. `extreme_value` —— 极值理论

**来源**：Fisher–Tippett–Gnedenko（GEV）；Pickands–Balkema–de Haan（GPD）；Hill (1975)。

**映射**：超阈值（POT）拟合 GPD → VaR_p = u + (β/ξ)[((1−p)/ζ_u)^{−ξ} − 1]，ES 闭式；Hill 估计尾指数 α = 1/ξ；块极大值 GEV 用于极端回撤。

**接口**：`hill_estimator(x, k)`、`hill_plot`、`fit_gpd(excesses)`、`pot_var_es(x, threshold, p, tail, quantile_u)`、`fit_gev_block_maxima`、`mean_excess`。

---

## 10. `sparse` —— 稀疏恢复

**来源**：压缩感知（Candès–Tao、Donoho 2006）；Tropp 的 OMP；Beck–Teboulle (2009) FISTA。

**映射**：从大量候选因子中选稀疏子集；用 k 只股票复制指数（低换手、低成本）。

**接口**：`omp(A, y, k, tol)`、`lasso_ista(A, y, lam, n_iter, fista=True)`（FISTA 加速）、`sparse_index_tracking(asset_returns, index_returns, k, long_only, sum_to_one)`。

---

## 11. `kelly` —— Kelly 准则与遍历性

**来源**：Kelly (1956) 信息论与赌博；Breiman (1961) 增长最优；Peters (2019) 遍历性经济学。

**映射**：连续 Kelly f* = μ/σ²，多资产 f* = Σ⁻¹(μ − r)；分数 Kelly c·f* 的回撤概率 P(DD ≥ α) = α^{2/c − 1}；时间平均 ≠ 集合平均（遍历性模拟）。

**接口**：`kelly_binary`、`kelly_continuous`、`kelly_multi_asset(mu, Sigma, r)`、`growth_rate`、`empirical_growth_rate`、`optimal_fraction_empirical`、`drawdown_probability(c, alpha)`、`simulate_growth`。

---

## 12. `spectral` —— 谱方法与 FFT 定价

**来源**：Fourier 分析；Carr–Madan (1999) 用特征函数 + FFT 快速定价。

**接口**：`periodogram`、`dominant_cycles`、`hilbert_phase`（瞬时相位 / 周期）、`bs_char_fn`、`heston_char_fn`、`carr_madan_call(S0, r, T, char_fn, strikes, alpha, N, eta)`。

**注意**：Carr–Madan 与 BS 闭式误差 < 2e-3；Heston 特征函数用 Albrecher 等 (2007) 的无分枝割形式。

---

## 13. `queueing` —— 排队论与限价订单簿

**来源**：Erlang 的排队系统；Cont–Stoikov–Talreja (2010) 的马尔可夫 LOB；Cont–de Larrard (2013) 的队列扩散极限。

**映射**：我方限价单前方有 q 个单位，市价单以 λ_mo 到达、前方撤单以 λ_c 到达、中间价以 ν 移动 → 成交概率为纯死亡过程的乘积公式；排队竞速 MC 衡量延迟的价值；`prob_mid_up` 给出队列不平衡下中间价上行概率。

**接口**：`fill_probability_pure_death(q_ahead, lam_mo, lam_cancel, nu_move)`、`expected_time_to_front`、`queue_race_mc`、`simulate_markov_lob`、`prob_mid_up(q_bid, q_ask, lam_lo, mu_mo, theta_cancel, n_sims, seed)`。

**接口**：`pseudo_observations`、`gaussian_copula_fit`、`gaussian_copula_sample`、`t_copula_fit(X, nu_grid)`（ν 轮廓似然）、`t_copula_sample`、`tail_dependence_t(rho, nu)`、`empirical_tail_dependence`、`kendall_tau_to_rho`。

## 15. `dynamical_systems` —— 非线性动力学与混沌

**来源**：Takens (1981) 嵌入定理；Grassberger–Procaccia (1983) 相关维数；Rosenstein 等 (1993) 最大 Lyapunov 指数；Eckmann 等 (1987) 递归图。

**映射**：正 Lyapunov 指数 = 预测时域有限（1/λ 为可预测步数）；RQA 的确定性、层状性可做状态指标。

**接口**：`takens_embedding(x, dim, tau)`、`correlation_dimension`、`largest_lyapunov_rosenstein(x, dim, tau, min_tsep, max_t)`、`recurrence_matrix`、`rqa`、`logistic_map`（校验：λ = ln 2）。

## 16. `manifold` —— 流形学习与谱聚类

**来源**：Coifman–Lafon (2006) 扩散映射；Ng–Jordan–Weiss (2002) 谱聚类。

**接口**：`gaussian_affinity`、`diffusion_maps(X, n_components, epsilon, t, alpha)`、`spectral_clustering`、`correlation_affinity`、`asset_clusters(corr, k, seed)`。

---

## 17. `wavelets` —— 小波多分辨率分析

**来源**：Haar (1910)、Daubechies (1988)；Percival–Walden 的 MODWT 与小波方差。

**映射**：把收益按时间尺度分解（日内 / 周 / 月），各尺度的方差与相关揭示不同频率参与者的行为；阈值去噪（Donoho–Johnstone）；MRA 分量之和 = 原序列。

**接口**：`dwt(x, wavelet, level)`、`idwt`、`wavelet_denoise(x, wavelet, level, mode)`、`modwt(x, wavelet, level)`、`wavelet_variance`、`wavelet_correlation`、`multiresolution`。

**注意**：已验证完美重构、MRA 可加性与方差分解恒等式；仅实现 Haar 与 db2 滤波器。
