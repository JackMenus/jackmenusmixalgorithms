# 01 控制论 `crossquant.control`

控制论看交易的方式：**系统状态不可直接观测（公允价、真实波动率、对冲比率）→ 用滤波器估计；目标是一个代价函数（执行成本 + 风险、库存惩罚、跟踪误差）→ 用动态规划 / 最优控制求策略；环境会变 → 用反馈与在线学习调整。** 本子包按“估计 → 决策 → 反馈”组织。

每节结构：**学科来源 → 量化映射 → 核心公式 → 接口 → 注意事项**。

---

## 1. `kalman` —— 卡尔曼滤波

**来源**：Kalman (1960)，线性高斯系统的最优状态估计，最早用于 Apollo 导航。

**映射**
- 时变回归 / 动态对冲比率：状态 β_t 随机游走，观测 y_t = [1, x_t]·β_t + ε_t。
- 局部水平模型：观测价格 = 公允价 + 微结构噪声，公允价随机游走（信噪比 `q_ratio`）。
- 随机波动率 QML（Harvey–Ruiz–Shephard 1994）：log r_t² = h_t + log ε_t²，把 log χ² 噪声近似为高斯后用 Kalman 估计 h_t。
- 非线性观测用 UKF（sigma 点传播）。

**核心公式**（预测 / 更新，Joseph 形式保证 P 对称正定）
```
x̂⁻ = F x̂ + B u,          P⁻ = F P Fᵀ + Q
K  = P⁻ Hᵀ (H P⁻ Hᵀ + R)⁻¹
x̂  = x̂⁻ + K (z − H x̂⁻),    P = (I − K H) P⁻ (I − K H)ᵀ + K R Kᵀ
RTS 平滑：C_t = P_t Fᵀ (P⁻_{t+1})⁻¹，x̂_t|T = x̂_t + C_t (x̂_{t+1|T} − x̂⁻_{t+1})
```

**接口**：`KalmanFilter(F, Q, R, H, x0, P0, B).filter(zs) / smooth(zs)`；`dynamic_hedge_ratio(y, x, delta, r)`（返回 `beta (T,2)`、`spread`、`spread_std`）；`optimize_noise_ratio`（极大化预测似然选 delta）；`local_level_filter(z, q_ratio)`；`sv_qml_filter(returns)`；`UnscentedKalmanFilter`。

**注意**：`delta` 决定系数漂移速度（过程噪声 = delta/(1−delta)），太大则 β 过拟合噪声；SV-QML 对接近零的收益不稳，内部加了偏移；UKF 的 α, β, κ 取 van der Merwe 默认值。

## 2. `particle_filter` —— 粒子滤波 / 序贯蒙特卡洛

**来源**：Gordon–Salmond–Smith (1993) 自举滤波；Andrieu–Doucet–Holenstein (2010) 粒子 MCMC。

**映射**：随机波动率模型 h_t = μ + φ(h_{t−1} − μ) + σ_η η_t，r_t = exp(h_t/2) ε_t 的观测非线性、非高斯，Kalman 近似有偏；粒子滤波直接给出 p(h_t | r_{1:t}) 与边际似然，PMMH 再给参数后验。

**核心公式**：权重 w_t^i ∝ p(r_t | h_t^i)；ESS = 1/Σ(w^i)²，低于阈值时系统重采样；log p̂(r_{1:T}) = Σ_t log mean_i(w_t^i)。

**接口**：`ParticleFilter(transition, loglik, init, n_particles, resample_threshold, seed).run(obs)`；`sv_particle_filter(returns, phi, sigma_eta, mu, n_particles)`；`pmmh_sv(returns, n_iter, ...)`；`systematic_resample`、`effective_sample_size`。

**注意**：1000–5000 粒子足够；PMMH 每步跑一次完整滤波，速度为 O(n_iter·T·N)。

## 3. `lqr` —— 线性二次调节与 Gârleanu–Pedersen 动态交易

**来源**：Bellman 动态规划 + Kalman 的 LQ 理论；离散代数 Riccati 方程（DARE）。

**映射**：Gârleanu–Pedersen (2013, 2016)：多资产、因子预测 f_t 按 Φ 衰减、二次交易成本 Λ，目标
```
max E Σ_t (1−ρ)^t [ x_tᵀ B f_t − (γ/2) x_tᵀ Σ x_t − (1/2) Δx_tᵀ Λ Δx_t ]
```
最优策略 **“向 aim 组合按固定比例靠近”**：
```
x_t = x_{t−1} + Λ⁻¹ A_xx (aim_t − x_{t−1}),   aim_t = (γΣ + A_xx)⁻¹ (B + A_xf (I − Φ)) f_t
A_xx 为 Riccati 型固定点；Λ ∝ Σ 时有闭式（单资产：a/λ 的闭式解）。
```
执行跟踪：状态 = 剩余量，控制 = 交易速率，LQR 给出“落后越多交易越快”的反馈增益。

**接口**：`lqr_discrete(A, B, Q, R)` → `K, P`；`finite_horizon_lqr`；`simulate_lqr`；`execution_tracking_lqr`；`gp_single_asset_rate`；`GarleanuPedersen(Sigma, Lambda, B, Phi, gamma, rho).markowitz(f) / aim(f) / step(x_prev, f) / simulate(f_path)`。

**注意**：aim 组合 = Markowitz 组合按因子衰减速度打折（快衰减因子权重更低）；`rho` 为贴现率，`rho=0` 时与经典解一致。

## 4. `mpc` —— 模型预测控制 / 多期组合优化

**来源**：过程工业的滚动时域控制（Richalet 等 1978）；Boyd 等 (2017) *Multi-Period Trading via Convex Optimization*。

**映射**：给定未来 H 期收益预测 μ_τ，求整条权重轨迹
```
max Σ_τ δ^τ [ μ_τᵀ w_τ − γ w_τᵀ Σ w_τ − c‖w_τ − w_{τ−1}‖₁ − d‖w_τ − w_{τ−1}‖₂² ]
s.t. 多头 / 满仓 / 杠杆约束
```
每期只执行第一步，下一期用新预测重解（滚动时域 = 对预测误差的反馈）。

**接口**：`MultiPeriodMPC(Sigma, gamma, tc_linear, tc_quadratic, long_only, fully_invested, leverage, discount).plan(w0, mu_path)`（返回整条轨迹）/ `.run(w0, mu_paths)`（滚动执行）。

**注意**：SLSQP 求解，适合资产数 ≤ 50、H ≤ 20；L1 成本用 `smooth_eps` 平滑；大规模问题应换 QP 求解器。

## 5. `execution` —— 最优执行与价格冲击

**来源**：二次代价的变分问题 / 线性系统的脉冲响应（传播子）。

**映射与公式**
- **Almgren–Chriss (2000)**：E[C] = ½γX² + εΣ|n_j| + (η̃/τ)Σn_j²，Var[C] = σ²τΣx_j²，η̃ = η − ½γτ；最优轨迹 x_j = X·sinh(κ(T−t_j))/sinh(κT)，cosh(κτ) = 1 + τ²λσ²/(2η̃)。λ 扫描给出效率前沿。
- **Bertsimas–Lo (1998)**：仅线性永久冲击、风险中性 → TWAP。
- **Obizhaeva–Wang (2013)**：块状订单簿 + 指数回弹 ρ：首尾块 X/(ρT+2)，中间匀速 ρX/(ρT+2)。
- **Gatheral–Schied–Slynko (2012)** 瞬时冲击传播子：成本 ½xᵀGx，G_ij = G(|t_i−t_j|)，最优 x ∝ G⁻¹1；指数核时与 OW 一致，幂律核给出更强的 U 形。
- **传播子价格路径**（Bouchaud 等 2004）：p_t = p_0 + Σ_{s<t} G(t−s)·ε_s·|v_s|^δ。
- **平方根冲击律**：I = Y·σ_daily·√(Q/ADV)，Y≈0.5–1。
- **实施缺口**：分解为延迟成本、执行成本、机会成本。

**接口**：`almgren_chriss(X, T, N, sigma, eta, lam, gamma, epsilon)`、`almgren_chriss_frontier`、`almgren_chriss_continuous`、`bertsimas_lo`、`transient_cost_matrix`、`optimal_schedule_transient(times, kernel, X)`、`obizhaeva_wang(X, T, N, rho, depth)`、`power_law_kernel(l0, tau0, beta)`、`propagator_price_path`、`square_root_impact(Q, adv, sigma_daily, Y)`、`implementation_shortfall`。

**注意**：传播子核 G 需正定（β ∈ (0,1) 的幂律、指数核满足）；否则出现价格操纵策略（Gatheral 2010 无套利条件）。

## 6. `market_making` —— 做市的随机最优控制

**来源**：HJB 方程 + 指数效用的维度约化（Ho–Stoll 1981 → Avellaneda–Stoikov 2008 → GLFT 2013）。

**映射与公式**
- **Avellaneda–Stoikov**：保留价 r = s − qγσ²(T−t)，总价差 δ^a + δ^b = γσ²(T−t) + (2/γ)ln(1+γ/k)。
- **GLFT（Guéant–Lehalle–Fernandez-Tapia 2013）**：成交强度 λ(δ) = A e^{−kδ}，库存 q ∈ [−Q, Q]。换元 u = −exp(−γx − γqs)·v_q(t)，HJB 化为线性 ODE 组 v' = M v（M 三对角），
```
δ^b*(t,q) = (1/k) ln(v_q / v_{q+1}) + (1/γ) ln(1+γ/k)
δ^a*(t,q) = (1/k) ln(v_q / v_{q−1}) + (1/γ) ln(1+γ/k)
```
  渐近解（T→∞）由 M 的 Perron 特征向量给出；闭式近似 δ^b ≈ (1/γ)ln(1+γ/k) + ((2q+1)/2)·√(γσ²/(2kA)·(1+γ/k)^{1+k/γ})。
- `simulate_market_making`：中间价布朗运动 + 泊松成交，比较不同报价策略的 PnL / 库存。

**接口**：`avellaneda_stoikov_quotes(s, q, t, T, gamma, sigma, k)`、`glft_closed_form_quotes(q, gamma, sigma, k, A)`、`glft_exact_quotes(...)`（`expm`，矩阵按最小特征值平移避免下溢）、`glft_asymptotic_quotes`、`simulate_market_making(quote_fn, ...)`、策略工厂 `as_strategy / symmetric_strategy / glft_strategy`。

**注意**：AS 的 δ 可能为负（对手盘激进），实际应取 max(δ, tick)；GLFT 库存上限 Q 决定矩阵尺寸；`order_placement` 库含带 alpha 漂移的版本，可互相校验。

## 7. `hjb` —— HJB 方程与随机最优控制

**来源**：Bellman 动态规划的连续时间形式；Merton (1969/1971)。

**映射与公式**
- Merton：dW = W[(r + π(μ−r))dt + πσ dB]，CRRA 效用 → π* = (μ−r)/(γσ²)。
- 通用一维 HJB：V_t + max_u [ b(x,u)V_x + ½σ²(x,u)V_xx + f(x,u) ] = 0，V(T,x) = g(x)。显式迎风有限差分，在网格上对 u 穷举取 max；CFL 条件自动选 dt。

**接口**：`merton_optimal_fraction(mu, r, sigma, gamma)`、`merton_value`、`solve_hjb_1d(x_grid, u_grid, drift, diffusion2, running, terminal, T, n_t, cfl)`、`merton_hjb_numeric`（数值 vs 闭式校验）。

**注意**：显式格式要求 dt ≤ cfl·dx²/max σ²；做市 / 执行类问题可把库存或剩余量作为状态 x、报价或速率作为 u 直接套用。

## 8. `changepoint` —— 变点检测

**来源**：Page (1954) CUSUM 统计过程控制；Adams–MacKay (2007) 贝叶斯在线变点检测。

**映射与公式**
- **CUSUM 滤波**（López de Prado 事件采样）：S⁺ = max(0, S⁺ + Δx)，S⁻ = min(0, S⁻ + Δx)，越过阈值 h 触发事件并重置。
- **Page CUSUM**：对均值偏移 k 的对数似然比累积，检出延迟与误报率由 (k, h) 控制。
- **BOCPD**：维护运行长度后验 P(r_t | x_{1:t})，风险率 H；Normal–Gamma 共轭 → Student-t 预测分布；输出 `prob_change[t] = P(r_t < window)`（最近 `window` 步内发生变点的后验概率）与 MAP 运行长度。

**接口**：`cusum_filter(series, threshold, use_diff)`、`page_cusum(x, mu0, mu1, sigma, h, two_sided, reset)`、`bocpd(x, hazard, mu0, kappa0, alpha0, beta0, max_run, window)`。

**注意**：P(r_t = 0) 恒约等于 hazard，这是数学性质而非 bug，所以用窗口累计概率做指标；`max_run` 截断运行长度以控制复杂度。

## 9. `bandits` —— 多臂老虎机

**来源**：Robbins (1952) 序贯设计；Auer 等 (2002) UCB1 / EXP3；Thompson (1933)；Li 等 (2010) LinUCB。

**映射**：交易场所选择（成交率 / 成本不同且随时间变化）、策略或参数的在线分配、做市报价档位选择。`venue_fill_reward` 给出“成交 − 成本”的奖励定义。

**核心公式**：UCB1 选 argmax μ̂_i + √(2 ln t / n_i)；Thompson 从后验采样；EXP3 权重 w_i ∝ exp(η Σ r̂_i)（对抗环境）；LinUCB：θ = A⁻¹b，UCB = xᵀθ + α√(xᵀA⁻¹x)。

**接口**：`UCB1`、`ThompsonBernoulli`、`ThompsonGaussian`、`EXP3`、`LinUCB(n_arms, dim, alpha, ridge)`，统一 `select(context=None)` / `update(arm, reward)`；`simulate_bandit(agent, reward_fn, T)`。

## 10. `optimal_stopping` —— 最优停止

**来源**：Snell 包络、自由边界问题；Longstaff–Schwartz (2001)。

**映射与公式**
- **LSM**：倒向回归继续价值 E[V_{t+1} | S_t] ≈ Σ β_k φ_k(S_t)，与立即执行价值比较；CRR 二叉树作为基准。
- **OU 价差最优平仓 / 建仓**（Leung–Li 2015）：V(x) = max(x − c, e^{−r dt} E[V(X_{t+dt}) | X_t = x]) 在网格上值迭代，得到平仓阈值 b*；建仓问题嵌套求解进入阈值 d*。

**接口**：`american_option_lsm(S0, K, r, sigma, T, n_steps, n_paths, basis)`、`crr_binomial_american`、`ou_optimal_exit(theta, kappa, sigma, r, cost, dt, grid)`、`ou_optimal_entry_exit`。

**注意**：LSM 只用 in-the-money 路径回归；OU 问题的网格需覆盖 θ ± 4σ/√(2κ)。

## 11. `pid` —— PID 反馈控制

**来源**：Minorsky (1922) 舵机控制。

**映射**：执行进度（实际 vs 计划成交量）误差 → 参与率调节；库存偏差 → 报价偏斜。
```
u = K_p e + K_i ∫e dt + K_d de/dt，积分项限幅（抗饱和），输出限幅。
```

**接口**：`PID(kp, ki, kd, out_min, out_max, derivative_filter, setpoint).step(error, dt)`（积分项限幅随输出限幅自动推导）；`simulate_execution_progress`。

---

## 12. `rls` —— 递推最小二乘

**来源**：Plackett (1950)；自适应滤波 / 自适应控制（Åström–Wittenmark）。

**映射**：在线时变 beta、在线 AR(1)（即在线 OU 参数）、任何“随到随更新”的回归。
```
K = P x / (λ + xᵀ P x),  θ ← θ + K (y − xᵀθ),  P ← (P − K xᵀ P) / λ
```
遗忘因子 λ ∈ (0.9, 1]，有效窗口 ≈ 1/(1−λ)。

**接口**：`RecursiveLeastSquares(dim, forgetting, delta).update(x, y) / predict(x)`；`adaptive_regression(X, y, forgetting)`。
