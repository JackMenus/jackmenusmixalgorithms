# 05 与其他库的接口

全栈系统由四个兄弟库加一个编排层组成，`crossquant` 是横向的“方法库”，被任何一层调用：

```
factor_mining/factormine  ──alpha──▶  quant/order_placement  ──child order──▶  routing_latency/latency_routing
        ▲                                     ▲                                          ▲
        │  特征 / 检验 / 去噪                   │  执行调度 / 做市 / 冲击 / 成交概率            │  延迟隐状态估计 / 场所选择
        └──────────────────── physics_math_control/crossquant ──────────────────────────────┘
                                              ▲
                              trading_system/quantstack（agent + 流水线 + 注册表）
```

所有库都位于 `/mnt/project-files/` 下，各自是独立 Python 包；`quantstack/core/registry.py` 的 `discover()` 会把兄弟库目录加入 `sys.path`。建议在其 `SIBLING_LIBS` 中加入：

```python
"crossquant": os.path.join(PROJECT_ROOT, "physics_math_control"),
```

## 1. 对 quantstack 的三个薄协议（`crossquant.adapters`）

集成层在 `quantstack/contracts/protocols.py` 预留了三个结构化子类型协议，`crossquant` 提供如下实现（无需导入 quantstack，顶层已再导出，`crossquant.X` 与 `crossquant.adapters.X` 等价）：

| 协议 | 方法 | 实现 | 说明 |
|---|---|---|---|
| `StateEstimator` | `update(observation: float, ts_us: int) -> float`<br>`predict(horizon_us: int) -> float` | `crossquant.KalmanTrendEstimator(level_var=1e-4, slope_var=1e-8, obs_var=1e-2)` | 局部线性趋势 Kalman：隐状态 = (水平, 斜率/秒)，按真实时间间隔外推；适合公允价、延迟的隐状态估计 |
| | | `crossquant.OUSpreadEstimator(forgetting=0.995, dt_sec=None)` | 在线 RLS 拟合 AR(1)，等价于离散 OU；`predict` 给出均值回复的条件期望，`params` 返回 (θ, κ, σ, 半衰期)；适合价差 |
| `Controller` | `step(error: float, dt_us: int) -> float` | `crossquant.PIDParticipationController(kp=1.0, ki=0.1, kd=0.0, out_min=-0.5, out_max=0.5)` | 抗积分饱和的 PID；输出为参与率调整量 |
| | | `crossquant.LQRTrackingController(q=1.0, r=0.1, dt_ref_sec=1.0, out_max=1.0)` | 一维 LQ 最优反馈 `u = -K·error`，`K` 由 DARE 解出；`r` 越大动作越温和 |
| `ImpactModel` | `expected_cost_bps(quantity: int, snapshot, duration_us: int) -> float` | `crossquant.SquareRootImpactModel(Y=0.5, horizon_volume=False, default_sigma=0.02, default_adv=1e6)` | 平方根冲击律 `Y·σ·√(Q/V)` + 半价差；`horizon_volume=True` 时用 `duration_us` 折算区间成交量 |
| | | `crossquant.AlmgrenChrissImpactModel(lam=1e-6, n_slices=10, perm_frac=0.1, ...)` | 在 `duration_us` 内按 AC 最优轨迹执行的期望成本（临时 + 永久冲击 + 价差） |

`snapshot` 只需提供 `mid`、`spread_bps`、`adv`、`volatility` 属性（与 `quantstack.contracts.MarketSnapshot` 一致，缺失时回退到默认值）。

一次性登记：

```python
import crossquant
crossquant.registry_entries()
# {"StateEstimator": {"crossquant.KalmanTrendEstimator": <class>, "crossquant.OUSpreadEstimator": <class>},
#  "Controller":     {"crossquant.PIDParticipationController": <class>, "crossquant.LQRTrackingController": <class>},
#  "ImpactModel":    {"crossquant.SquareRootImpactModel": <class>, "crossquant.AlmgrenChrissImpactModel": <class>}}
```

约定：时间戳微秒整数 `ts_us`；成本用基点；随机算法接受 `seed`。

### 使用示例

```python
import crossquant as cq

est = cq.KalmanTrendEstimator(level_var=1e-4, slope_var=1e-8, obs_var=1e-2)
for ts_us, px in [(0, 100.0), (1_000_000, 100.05), (2_000_000, 100.09)]:
    est.update(px, ts_us)
fair_5s = est.predict(horizon_us=5_000_000)

ctrl = cq.LQRTrackingController(q=1.0, r=0.1)
adjust = ctrl.step(error=0.08, dt_us=1_000_000)      # 进度落后 8% → 参与率上调量

impact = cq.AlmgrenChrissImpactModel(lam=1e-6)
cost_bps = impact.expected_cost_bps(quantity=50_000, snapshot=snap, duration_us=30 * 60 * 1_000_000)
```

## 2. 被因子挖掘库（`factormine`）调用

`crossquant` 提供的“特征生成器”与“统计检验”都是纯函数，可直接作为候选因子或过滤器：

| 用途 | 函数 | 返回 |
|---|---|---|
| 路径形状特征 | `mathematics.signatures.sliding_signature_features(series, window, depth)` | `(T', n_features)` 签名特征矩阵 |
| 记忆 / 标度特征 | `physics.hurst.rolling_hurst(returns, window)`、`physics.hurst.dfa` | 滚动 Hurst |
| 复杂度特征 | `physics.entropy.permutation_entropy`、`sample_entropy`、`spectral_entropy` | 标量 / 滚动 |
| 多尺度特征 | `mathematics.wavelets.multiresolution(x, level)`、`mathematics.koopman.ssa` | 各尺度分量 |
| 平稳化 | `mathematics.fracdiff.frac_diff_ffd(x, d)` + `find_min_d` | 平稳且保留记忆的序列 |
| 因子筛选 | `physics.entropy.mutual_information_ksg`、`transfer_entropy`、`mathematics.sparse.omp` | 非线性相关 / 稀疏子集 |
| 协整 / 平稳检验 | `mathematics.timeseries.adf_test`、`ljung_box` | 统计量、p 值 |
| 隐状态 | `control.kalman.dynamic_hedge_ratio`、`local_level_filter`、`control.particle_filter.sv_particle_filter` | 时变系数 / 水平 / 波动率 |
| 变点标签 | `control.changepoint.cusum_filter`（事件采样）、`bocpd` | 事件索引 / 变点概率 |

## 3. 被挂单策略库（`order_placement`）调用

`order_placement` 已有 AS / GLFT / AC / OW / 传播子 / 排队的实现；`crossquant` 提供可互相校验的独立实现与若干补充：

- **校验**：`control.execution.almgren_chriss` 闭式解、`optimal_schedule_transient` 的 `x ∝ G⁻¹1` 一般解、`control.market_making.glft_exact_quotes`（有限期精确解）与 `glft_asymptotic_quotes`（Perron 向量）。
- **补充**：`control.lqr.GarleanuPedersen`（多资产、有成本、有信号衰减的动态组合）、`control.mpc.MultiPeriodMPC`（带约束的多期）、`control.optimal_stopping.ou_optimal_exit`（价差的最优平仓阈值）、`mathematics.queueing.fill_probability_pure_death`（队列成交概率闭式）、`physics.first_passage.*`（止盈止损概率）。
- **做市参数**：`physics.hawkes.fit_hawkes` 估计订单到达强度，`physics.ou_process.fit_ou` 估计 alpha 的均值回复，均可喂给 GLFT 的 `A, k, σ`。

## 4. 被路由延迟库（`latency_routing`）调用

- **延迟隐状态**：`crossquant.KalmanTrendEstimator` 直接实现 `StateEstimator`，可用于每个场所的延迟水平 / 漂移估计；`control.changepoint.bocpd` 检测延迟分布突变。
- **场所选择**：`control.bandits.UCB1 / ThompsonGaussian / EXP3 / LinUCB`，`venue_fill_reward` 给出成交 - 成本的奖励定义。
- **成交概率**：`mathematics.queueing.queue_race_mc`（延迟 vs 队列前方撤单的竞速）。

## 5. 被 agent（`quantstack.agent`）调用

agent 做“成本 – alpha 权衡”“状态感知”“策略切换”三件事时，可分别调用：

| agent 需求 | crossquant 工具 |
|---|---|
| 成本 – alpha 权衡 | `ImpactModel` 实现（平方根 / AC）、`control.execution.implementation_shortfall` |
| 市场状态感知 | `pipelines.regime.regime_dashboard`（Hurst、熵、Wasserstein、Fisher–Rao、BOCPD） |
| 策略 / 参数切换 | `control.bandits.*`（在线分配）、`control.changepoint.bocpd`（切换触发） |
| 风险限额 | `mathematics.extreme_value.pot_var_es`、`mathematics.kelly.kelly_multi_asset`、`drawdown_probability` |
| 组合层 | `physics.random_matrix.denoise_covariance` → `physics.networks.hierarchical_risk_parity` 或 `mathematics.optimal_transport.wasserstein_dro_mean_variance` |

推理强度建议（与项目总体设定一致）：需要推导 / 校准模型（HJB 边界、GLFT 参数、DRO 半径、Hawkes 多变量核）时走高推理强度；滚动调用纯数值函数（滤波更新、报价计算、特征生成）时无需模型推理，直接执行。

## 6. 数据格式约定

| 项目 | 约定 |
|---|---|
| 时间序列 | `np.ndarray`，时间升序，`(T,)` 或 `(T, n)` |
| 收益 | 小数；对外成本 / 价差用基点 |
| 时间戳 | 适配器层用微秒整数 `ts_us`；数值函数用以“期”为单位的 `dt` |
| 随机数 | `seed: int | None` 或 `rng: np.random.Generator` |
| 协方差 | 对称正定 `np.ndarray`，`_utils.ensure_spd` 可修复 |
| 返回 | `dict`（含中文说明的键）或 `np.ndarray` |
