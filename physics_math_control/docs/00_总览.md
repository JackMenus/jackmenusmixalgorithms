# 00 总览：为什么要一个“跨学科算法库”，以及怎么用它

## 1. 定位

量化交易中最有生命力的方法，很多并不诞生于金融：

| 学科 | 带来的视角 | 典型迁移 |
|---|---|---|
| **控制论** | 把交易看成“带噪声观测的动态系统 + 代价函数 + 反馈” | Kalman 滤波估计隐状态；LQR / MPC / HJB 给出最优策略；PID 做执行进度反馈；bandit 做在线决策 |
| **物理学** | 把市场看成“多体相互作用系统”，关心标度律、相变、能量景观、扩散 | Langevin → OU 均值回复；地震余震 → Hawkes 订单流；核能级统计 → 随机矩阵去噪；分形 → Hurst 与粗糙波动率；吸收边界 → 止损概率；退火 → 组合优化 |
| **数学** | 提供度量、表示与结构：分布之间的距离、路径的代数表示、算子的谱、数据的拓扑 | 最优传输监测分布漂移；路径签名做路径特征；Koopman/DMD 线性化动力学；持续同调做崩盘预警；极值理论度量尾部 |

`crossquant` 把这些算法按学科组织成三个子包，每个模块的 docstring 都包含 **学科来源 → 量化映射 → 核心公式 → 参考文献**，再用 `pipelines/` 把它们串成可运行的端到端流程，用 `adapters.py` 对接全栈交易系统。

## 2. 按“量化问题”反查算法

实际工作中更常见的问题是“我要解决 X，该借哪个学科的工具？”下表按量化问题反查：

### 2.1 信号 / 因子挖掘
| 问题 | 工具 | 模块 |
|---|---|---|
| 价差是否均值回复？半衰期多少？ | OU 过程精确 MLE、ADF、AR(1) 半衰期 | `physics.ou_process`、`mathematics.timeseries` |
| 对冲比率随时间变化 | Kalman 动态回归、RLS | `control.kalman`、`control.rls` |
| 趋势还是均值回复市场？ | Hurst（R/S、DFA、方差比）、排列熵 | `physics.hurst`、`physics.entropy` |
| 路径形状本身作为特征 | 截断签名 / 对数签名、lead-lag、Lévy 面积 | `mathematics.signatures` |
| 平稳化但保留记忆 | 分数阶差分 FFD + 最小 d 搜索 | `mathematics.fracdiff` |
| 非线性依赖与信息流向 | KSG 互信息、传递熵矩阵 | `physics.entropy` |
| 多尺度 / 周期成分 | 小波 MRA、SSA、周期图、Hilbert 相位 | `mathematics.wavelets`、`mathematics.koopman`、`mathematics.spectral` |
| 可预测性（混沌程度） | 最大 Lyapunov 指数、相关维数、RQA | `mathematics.dynamical_systems` |
| 从一堆候选因子里挑稀疏子集 | OMP、LASSO/ISTA | `mathematics.sparse` |
| 隐状态非线性 / 非高斯 | 粒子滤波、UKF | `control.particle_filter`、`control.kalman` |

### 2.2 执行 / 挂单
| 问题 | 工具 | 模块 |
|---|---|---|
| 大单怎么切分 | Almgren–Chriss（含效率前沿）、Bertsimas–Lo | `control.execution` |
| 订单簿有回弹（瞬时冲击） | Obizhaeva–Wang、任意衰减核传播子的最优调度 | `control.execution` |
| 冲击成本估计 | 平方根冲击律、传播子价格路径、实施缺口分解 | `control.execution` |
| 多资产 + 成本的动态再平衡 | Gârleanu–Pedersen、多期 MPC | `control.lqr`、`control.mpc` |
| 执行进度落后 / 超前时怎么调参与率 | PID、LQ 跟踪 | `control.pid`、`control.lqr`、`adapters` |
| 限价单多久能成交？挂还是吃？ | 纯死亡过程成交概率、排队竞速、马尔可夫 LOB | `mathematics.queueing` |
| 订单流聚簇与成交强度 | Hawkes 过程（单 / 多变量） | `physics.hawkes` |
| 多个交易场所 / 算法在线选择 | UCB1、Thompson、EXP3、LinUCB | `control.bandits` |

### 2.3 做市
| 问题 | 工具 | 模块 |
|---|---|---|
| 库存风险下的双边报价 | Avellaneda–Stoikov、GLFT（闭式 / 精确 / 渐近） | `control.market_making` |

| 报价后的成交 / 撤单竞速 | 排队论、Hawkes 强度 | `mathematics.queueing`、`physics.hawkes` |

### 2.4 组合与风险
| 问题 | 工具 | 模块 |
|---|---|---|
| 协方差噪声太大 | Marchenko–Pastur 裁剪、RIE、Ledoit–Wolf | `physics.random_matrix` |

|---|---|---|

## 3. 使用约定

- 输入接受 `list` / `np.ndarray`，内部统一转为 `float64`；时间序列按时间升序，形状 `(T,)` 或 `(T, n)`。
- 返回值：单一数值用 `float`，多结果用 `dict`（键名中文注释见各函数 docstring），路径类结果为 `np.ndarray`。
- 随机性：所有随机算法接受 `seed`（int）或 `rng`（`numpy.random.Generator`）。
- 单位：收益为小数（0.01 = 1%），`adapters` 层对外用基点 bps，时间戳用微秒整数 `ts_us`。
- 依赖：仅 `numpy`、`scipy`；`matplotlib` 只在示例中可选使用。

## 4. 验证策略

库中的通用求解器都附带“已知答案”检验，可当作使用模板：

| 求解器 | 校验方式 |
|---|---|
| `control.hjb.solve_hjb_1d` | Merton 问题的最优比例与闭式 μ/(γσ²) 对照 |
| `control.execution.optimal_schedule_transient` | 指数核时与 Obizhaeva–Wang 闭式一致 |
| `control.market_making.glft_exact_quotes` | 与渐近 Perron 向量解、闭式近似在长周期一致 |
| `mathematics.signatures.signature` | Chen 恒等式（深度 4）；圆周路径的对数签名面积 = π |
| `mathematics.wavelets.dwt/idwt` | 完美重构、MRA 可加性、小波方差之和 = 总方差 |
| `mathematics.spectral.carr_madan_call` | 与 BS 闭式误差 < 2e-3 |
| `mathematics.queueing.fill_probability_pure_death` | 与蒙特卡洛一致 |
| `physics.rough_volatility.rbergomi_simulate` | Var(Y_T)=1、S 为鞅 |
| `physics.hawkes.fit_hawkes` | 模拟参数回收 + 残差 KS 检验 |
| `physics.random_matrix.mp_bounds` | 纯噪声矩阵的经验谱落在 MP 边界内 |

## 5. 路线图（可按需扩展）

1. **神经网络增强版**（需 torch）：神经 Hawkes、Koopman-Transformer、PINN 求解 HJB/BS、RL 做市 —— 文献见 `04_前沿文献索引.md`，本库已提供其经典核心作为基线与校验器。
2. **多资产 GLFT / 一般强度函数做市**（Guéant 2017）与 **带 alpha 信号的 AC**（`order_placement` 库已含漂移项版本，可互相校验）。
3. **平均场博弈（MFG）执行**（N 个交易者的瞬时冲击均衡，arXiv:2501.09638）。
4. **Wasserstein DRO 的高维认证版本**（arXiv:2608.07032）、可训练的 OT 歧义集（arXiv:2509.12689）。
5. 与 `factormine` 的因子评价流水线对接：把签名 / 熵 / Hurst / 小波特征作为候选因子批量产出。
