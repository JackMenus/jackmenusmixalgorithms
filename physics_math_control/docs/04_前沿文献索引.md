# 04 前沿文献索引

按主题分组：先列 **经典奠基**（本库实现的对象），再列 **2023–2026 前沿**（方向与本库的衔接点）。arXiv 编号可直接访问 `https://arxiv.org/abs/<编号>`。最后一栏标注本库对应模块。

> 说明：前沿论文中依赖神经网络（Transformer、神经 Hawkes、PINN、深度 RL）的部分本库未实现（仅 numpy/scipy），但其“经典核心”都已提供，可作为基线、特征生成器或校验器。

## 阅读路线建议

1. **先读教材**：Cartea–Jaimungal–Penalva（随机控制）、Bouchaud–Bonart–Donier–Gould *Trades, Quotes and Prices*（经济物理与微观结构）、López de Prado（机器学习 + 统计工具）。
2. **再读本库每个模块 docstring 中的“核心公式”**，用 `examples/` 跑一遍。
3. **前沿方向**按需深入：做执行 → §1 的 MFG 与 RL；做订单流 → §4 的神经 Hawkes；做风险 → §5 的 DRO；做特征 → §6 签名与 §7 Koopman。
