# 因子挖掘前沿算法综述（截至 2026 年 10 月）

本文梳理公式化 alpha 因子与机器学习因子挖掘的主要技术路线，并标注它们在 `factormine` 中的对应实现。
“已实现”指库内有可运行代码；“接口预留”指提供了接口与样板，完整版需要额外依赖（如 PyTorch）。

## 1. 因子表达与算子体系

| 工作 | 要点 | 库内对应 |
|---|---|---|
| Kakushadze, *101 Formulaic Alphas*（Wilmott, 2016） | 公式化 alpha 的标准写法：ts_rank / decay_linear / correlation / scale 等算子 | `operators.py` 全部收录，可作为 GP 热启动种子 |
| 国泰君安 191 因子（2017 研报） | A 股日频量价因子集合 | 同上算子体系可直接表达 |
| Qlib（Yang et al., 2020, Microsoft） | Alpha158/Alpha360 特征、表达式引擎 | `expression.py` 带缓存的表达式求值器 |

## 2. 遗传规划 / 进化算法（已实现：`gp.py`）

- **gplearn 式 GP 符号回归**：表达式树的交叉、子树变异、点变异；适应度为 IC 类指标。
- **AutoAlpha**（Zhang et al., 2020, arXiv:2002.08245）：分层进化；用与已有因子的相关性做多样性约束，避免种群坍缩到同一个 alpha；以低深度公式热启动。
- **AlphaEvolve**（Cui et al., SIGMOD 2021）：在公式中引入可学习参数与跨资产关系算子。（注意与 DeepMind 2025 年的同名通用代码进化系统区分；后者的“LLM 提案 + 自动评测 + 进化”框架也被借鉴到下面的 LLM 路线里。）

库内实现：适应度 = |训练段 RankIC| − 复杂度惩罚 − 与因子池最大相关 × 惩罚；每代把优秀个体投递到共享的 `FactorPool`，入池须满足相关性上限。

## 3. 强化学习（已实现：`rl.py`）

- **AlphaGen**（Yu et al., KDD 2023）：把公式写成逆波兰（RPN）记号序列，策略网络逐 token 生成；奖励是“新因子加入因子池后，池的线性合成 IC 的提升”。这让搜索目标从“单个强因子”变成“协同的因子集合”，是该方向的关键转折。
- **QuantFactor REINFORCE**（Zhao et al., 2024, arXiv:2409.05144）：指出公式生成是确定性转移的 MDP，用带基线的 REINFORCE 替代 PPO，方差更小、收敛更稳。
- **Alpha²**（Xu et al., 2024, arXiv:2406.16505）：用语法/量纲约束屏蔽非法动作，配合 MCTS 搜索。
- **RiskMiner**（Ren et al., ICAIF 2024）：风险敏感的 MCTS 因子搜索。

库内实现：RPN 记号表 + 合法性掩码 + 上下文线性 softmax 策略 + REINFORCE（滑动基线、熵正则）；奖励为池合成 IC 增量。策略类可替换为 LSTM/Transformer。

## 4. 生成-预测与动态合成（已实现：`combine.DynamicCombiner`）

- **AlphaForge**（Shi et al., AAAI 2025, arXiv:2406.18394）：生成器 + 预测器联合挖掘；更重要的是**动态合成**：每期根据近期 IC 重新挑选 Top-K 因子并重估权重，应对因子时变有效性。
- 库内 `DynamicCombiner`：每期用过去 `lookback` 期已实现 IC（额外滞后 horizon 期以避免前视）选 Top-K，按 IC 或 ICIR 加权。

## 5. LLM / 智能体驱动（已实现：`llm.py`）

| 工作 | 核心思想 |
|---|---|
| **Alpha-GPT**（Wang et al., 2023, arXiv:2308.00016） | 人机交互：研究员给想法 → LLM 翻译成公式 → 回测 → 总结反馈 |
| **AlphaAgent**（Tang et al., KDD 2025, arXiv:2502.16789） | Idea/Factor/Eval 三智能体；用 AST 相似度做原创性正则、假设-公式一致性、复杂度控制来对抗 alpha 衰减 |
| **R&D-Agent-Quant**（Microsoft, 2025, arXiv:2505.15155） | 研究/开发两阶段，因子与模型联合迭代，多臂赌博机调度方向 |
| **Alpha Jungle：LLM + MCTS**（Shi et al., AAAI 2026, arXiv:2505.11122） | 把 LLM 作为 MCTS 的扩展算子，回测结果作为节点价值，在有潜力的公式附近做定向精修 |
| **FactorMiner**（2026, arXiv:2602.14670） | 自我进化智能体：把成功/失败经验沉淀为“技能 + 经验记忆”，指导后续生成 |

库内实现：`LLMAlphaAgent` 闭环——提示词含字段/算子说明、已有因子、上一轮回测反馈与历史最佳思路（经验记忆）；生成后做语法、复杂度、AST 原创性校验，再回测入池。客户端可插拔：`AnthropicClient`（默认 `claude-fable-5-1`，effort=max，用于强推理）、`MockLLM`（离线测试）。

**尚未实现、建议后续加入**：AlphaAgent 的“假设-公式一致性”LLM 评审；Alpha Jungle 的 MCTS 精修（可复用 `FactorPool.score` 作价值函数）。

## 6. 深度学习因子（接口预留：`neural.py`）

- **Gu, Kelly & Xiu**（RFS 2020）：MLP/树模型横截面收益预测的经典实证。
- **FactorVAE**（Duan et al., AAAI 2022）：把因子视为隐变量的概率动态因子模型。
- **HIST**（Xu et al., 2021）：利用概念/行业图挖掘共享信息。
- **DoubleAdapt**（Zhao et al., KDD 2023）：元学习做数据与模型双重适配，应对分布漂移。
- **MASTER**（Li et al., AAAI 2024）：市场引导的股票 Transformer。

库内提供零依赖 numpy MLP，损失为“横截面相关最大化”，输入可以是已挖出的公式因子。更强模型按同样 fit/predict 接口接入即可。

## 7. 因子组合与去冗余（已实现：`combine.py`）

- 等权 / IC 加权 / ICIR 加权；
- **最大化复合 IC_IR**：w ∝ Σ_IC⁻¹ μ_IC（Qian & Hua，《Quantitative Equity Portfolio Management》），协方差向对角收缩；
- **岭回归**：堆叠 (t, asset) 样本，GKX 2020 的线性基准；
- **施密特正交 / 对称（Löwdin）正交**：后者与顺序无关、与原因子距离最小；
- 贪心去相关选择。

## 8. 评估方法（已实现：`evaluate.py`）

IC、RankIC、ICIR、IC t 值、分层收益与单调性、多空收益/夏普、换手代理、IC 衰减（累计/边际）、因子相关矩阵。
AlphaEval（2025, arXiv:2508.13174）指出只看 IC 会高估因子，建议同时看稳定性、鲁棒性、多样性和可解释性。本库在入库时做了样本内外方向一致性检查，并把半衰期交给执行层使用。

## 9. 与执行层的衔接

因子信号的半衰期决定执行的紧迫度：`AlphaSignal.urgency = 1/半衰期`。半衰期短的信号需要更激进的挂单与更低延迟的路由；半衰期长的可以被动挂单、等返佣。详见《接口规范.md》。
