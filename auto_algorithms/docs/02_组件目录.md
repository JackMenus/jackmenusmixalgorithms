# 02 组件目录与新算法实现

`python -m autoalgo components` 打印完整目录（`autoalgo/catalog.py`）。本文说明 `autoalgo/components/` 里的新实现。

## regime.py —— 市场状态探测

- `rolling_hurst(returns, window, step)`：窗口末端的 DFA Hurst（crossquant `physics.hurst.dfa`），步长间前值填充；长度 <64 时退化为方差比近似。
- `change_probability(x, hazard, window)`：BOCPD（crossquant `control.changepoint.bocpd`）的"最近 window 步内发生变点"的后验概率；输入先做**扩展窗口**标准化以保证因果。
- `RegimeDetector.transform(market_returns) -> DataFrame(hurst, prob_change, regime)`。

## operators.py —— 跨学科因子算子（注入 factormine）

| 算子 | arity | 对照 | 备注 |
|---|---|---|---|
| `ts_fracdiff(x, d)` | xc | `frac_diff_ffd` 精确一致 | 阈值 1e-3，窗口 ≤120 |
| `ts_vr(x, w)` | xw | Lo–MacKinlay VR(5) | log VR，>0 趋势 |
| `ts_hurst(x, w)` | xw | DFA | 窗口 ≥32，步长 w//4 |
| `ts_perm_entropy(x, w)` | xw | `permutation_entropy` | 三阶序数模式，向量化 |
| `ts_kalman_resid(x, q)` | xc | 局部水平模型稳态增益 | K = (P/R)/(P/R+1) |
| `ts_levy_area(x, y, w)` | xxw | `levy_area` 精确一致 | 按 w·σ_x·σ_y 归一 |

`register_all()` 幂等；同时为 `xc` 算子登记 GP 的常数候选。

## alpha.py —— AlphaModel

- `RegimeGatedAlpha`：分状态 `fit_weights`；`predict` 用当前状态权重；置信度 ×(1 − shrink·p_change)。
- `SignatureAlpha`：`signature_features(paths, window)` 向量化 Chen 恒等式，与 `crossquant.signature` 一致到 1e-15；池化岭回归。
- `CrossOperatorMinedAlpha`：`register_all()` → `mine_factors(GP)` → `factormine.AlphaModel`；`extended_share()` 报告跨学科算子占比。
- 三者都有 `score_panel(panel)`：逐行只用历史的一次性出分，评估台用它加速（测试断言与逐日 `predict` 完全一致）。

## portfolio.py —— PortfolioConstructor

`DenoisedRiskParityConstructor`：`fit(panel, as_of)` 存最近 lookback 期收益 → `denoise_covariance`（rie / clip / lw / none）→ 两种配置器：

- `allocator="mv"`（默认）：去噪协方差的最大特征对给出共同因子载荷 β̂=√λ₁·v₁ 与特质方差 σ²_ε=diag(Σ̂)−β̂²，腿内 w_i ∝ μ_i/σ²_ε,i（Grinold：μ_i=IC·σ_i·z_i 时即 w_i ∝ z_i/σ_i）；`neutralize="dollar"` 按 net_target 分两腿，`"beta"` 用两腿规模抵消 Σw_iβ̂_i。不剔除、不反向任何标的，保留分散度。
- `allocator="hrp" / "ivp" / "equal"`：每腿风险权重 w_risk，再 w ∝ w_risk^(1−tilt)·(|z|/mean|z|)^tilt。

之后迭代裁剪单票上限；`kelly_fraction>0` 时用多资产 Kelly 的分数杠杆**只做去杠杆**（不会放大到超过 gross_target）。`cost_threshold_bps` 默认 0：弱 alpha 的期望收益只有 2–3 bps/σ，硬门槛会把两腿压成一两只股票。无历史收益时退化为信号加权（等价参考实现）。

## execution.py —— ExecutionStrategy / Factory

`KalmanPIDExecution(QuantstackExecution)`：`plan` 用 `AlmgrenChrissExec.plan`；`urgency_target` 加控制器修正与 Kalman 漂移调节；`passive_price` 按预测改善 / 后撤一跳。
`AutoExecutionFactory`：包裹挂单库工厂，`available()` 多一个 `kalman_pid`。

## selector.py —— StrategySelector

`BanditStrategySelector`：8 维上下文、LinUCB、前 warmup 次沿用 `choose_strategy`；`attach(pipeline)` 订阅 `order_done`，用 TCA 实现偏差回填奖励。

## routing.py —— Router 叠加层

`BayesianVenueRouter(base, venues)`：吃单多场所 → 按 Thompson 采样重分配份额；吃单单场所 → 在同价、可见量足够的场所间按采样换场所；
被动单 → 退化场所改投；`on_event` 先透传底层，再用成交价 vs 路由时中间价更新后验，用回报延迟做 BOCPD 退化监测。
